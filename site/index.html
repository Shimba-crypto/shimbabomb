ShimbaBomb (SB)

English-like scripting that compiles to native C.

1write it like english

no curly braces. no semicolons. just sentences that end with a dot.

hello.sb 
SB
set name to "world".
say "hello, ${name}!".

# loops, conditions, functions — all plain words
count i from 1 to 5 then
  say i.
end
it compiles. for real. 
$ sb build hello.sb      # → native binary, no runtime
$ ./hello
hello, world!

2real gui — not html

gui.sb 
SB
shimgui_window with "My App" and 460 and 320.

shimgui_run with.

3errors you can actually read

catch gives you a note, and a secret map with the full story.

try
    set y to 10 minus "oops".
catch e
    say e.                    # the short note
    say e_info["line"].       # where it broke
    say e_info["trace"].      # how you got there
end

4install it

git clone https://github.com/Shimba-crypto/shimbabomb.git
cd shimbabomb
./install.sh              # grabs gtk/curl deps, builds, installs
sb examples/hello.sb      # boom.

5what's in the box

  • sb — interpreter, REPL, debugger, LSP, formatter
  • sb build — compile to a standalone native binary
  • shimgui — real GTK windows, labels, buttons, inputs
  • serve / fetch — web server + http client, built in
  • sb pack deb|rpm|exe — ship it as installers
  • std/ — maths, lists, crypto, datetime, fp, ui, shimtorch

psst — every statement ends with a dot. that's the whole rule.
